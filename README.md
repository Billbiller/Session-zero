# Session Zero

Find a D&D (or other tabletop) group, or post one you're running, and keep
track of the campaign once you're in one.

See [`claude/progress.md`](./claude/progress.md) for the full spec, backlog,
tooling notes, and session history.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Testing

```bash
npm test        # vitest: unit + HTTP integration
npm run lint
npm run build
```
